Download the subway static feed from mta.info/developers, unzip it, and upload transfers.txt (and optionally stops.txt for station names) here to replace the built-in estimates with the MTA's exact min_transfer_time values.

Built-in figures are rough estimates for common transfer complexes, meant for quick reference — not official MTA data. For exact numbers per platform pair, load the real GTFS transfers.txt feed above; it reports min_transfer_time in seconds for each stop pair, including in-system walks. Source for this app is a single static HTML file — view source or ask for the code to adapt it.
